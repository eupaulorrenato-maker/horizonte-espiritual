# Horizonte Espiritual

Portal de acolhimento e espiritualidade universal, com foco no público 50+ e respeito a todas as crenças e tradições de fé do Brasil.

## Funcionalidades
1. Seleção personalizada entre 16 tradições religiosas.
2. Termômetro do coração com palavra diária de conforto.
3. Módulo de Vela Virtual interativa com compartilhamento no WhatsApp.
4. Catálogo de Orações Fortes e Rezas tradicionais (Umbanda, Candomblé, Católicas, Salmos, Espíritas).
5. Biblioteca Sagrada em domínio público.
6. Páginas institucionais de transparência, blog e apoio voluntário via PIX.
